## 프로젝트 소개


**같은 책을 읽는 사람들과 감상을 공유하는 기록 중심 독서 플랫폼**

THIP은 웹과 앱을 통해 언제 어디서나 접근 가능한 커뮤니티형 독서 기록 플랫폼이에요.

원하는 책을 골라 독서하고 책에 대한 감상을 다양한 형태로 기록할 수 있어요.
